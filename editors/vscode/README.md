# TeXLoom comments for VS Code

The comments and suggested changes of a [TeXLoom](https://texloom.org) project, beside the text they are about, in the folder you have open: as comment threads like a pull request review, with **reply** and **resolve**. A comment that mentions you (`@yourname`) is open when you arrive.

It needs a TeXLoom folder (one the desktop app or `texloom run` keeps in step with a project) and TeXLoom itself: the app, or the `texloom` command-line helper. It starts `texloom lsp`, TeXLoom's language server, so the same comments also work in Neovim, Emacs, Helix, Zed and Sublime Text (see the main README).

Settings: `texloom.command` (where TeXLoom is, if not on your PATH), `texloom.comments` (threads, Problems panel entries, or both).

Suggested changes are shown, but accepted or rejected in the web app's Review tab, where the change can be seen. Starting new comments from VS Code isn't there yet.
